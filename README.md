# Clean Your Mind

A visual library of every audio plugin on the computer, plus usage statistics read from Bitwig projects.
Part of the Primal Rage Lab line (Crumble, Voice Fucker).

- Finds VST3, VST2 (`.dll` / `.vst`), CLAP and AU files without launching them.
- One card per plugin, whatever formats it comes in. Drag a card onto a Bitwig track to load it.
- Screenshots per card: drop a file or paste from the clipboard, then crop and zoom.
- Reads `.bwproject` files: how many times each plugin was used, in how many projects, when last, how often per year.
- "Can delete" list and a reversible quarantine.

Builds for Windows and macOS run on GitHub Actions and land in the `latest` release.
See `Installer/HOW TO INSTALL.txt`.
